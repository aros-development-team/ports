# libzip

libzip is a C library for reading, creating, and modifying ZIP archives. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches and adapts the upstream sources for the configured AROS SDK; this directory is not a standalone library distribution.

The recipe builds libzip with CMake and installs it into the configured AROS developer environment.
