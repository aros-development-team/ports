# SDL Scavenger

SDL Scavenger is a platform puzzle game based on the Scavenger / Lode Runner style of play. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Games/Platform/SdlScavenger`.
