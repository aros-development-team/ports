# ZuneARC

ZuneARC is a graphical archive-management utility for AROS. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Utilities/Archive/ZuneARC`.

The recipe also installs the archive tool's configuration files and icons.
