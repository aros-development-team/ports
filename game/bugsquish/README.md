# Bug Squish

Bug Squish is an arcade game about squashing bugs. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Games/Action/Bugsquish`.
