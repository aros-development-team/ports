# Naev

Naev is a space-trading and combat game. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Games/Misc/Naev`.

The recipe fetches a separate game-data archive in addition to the upstream source.
