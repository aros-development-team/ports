# GNU a2ps

GNU a2ps converts text and other input formats to PostScript for printing. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Utilities/Print/A2ps`.
