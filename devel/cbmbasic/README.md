# Commodore BASIC

CBMBasic provides a Commodore BASIC interpreter outside the original hardware. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/$(AROS_DIR_DEVELOPER)/CBMBasic`.
