# Biniax 2

Biniax 2 is an arcade-style matching and puzzle game. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Games/Action/Biniax2`.
