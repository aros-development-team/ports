# ZuneView

ZuneView is a Zune-based picture viewer and image-processing application. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/MultiMedia/Gfx/ZuneView`.

The recipe also installs supplied catalogs and application assets.
