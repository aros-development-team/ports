# ScummVM

ScummVM runs supported classic adventure games through reimplemented game engines. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Emu/Scummvm`.
