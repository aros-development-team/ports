# libmpeg2

libmpeg2 is a library for decoding MPEG-2 video. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches and adapts the upstream sources for the configured AROS SDK; this directory is not a standalone library distribution.

The recipe configures libmpeg2 without its SDL component and installs it in the AROS developer environment.
