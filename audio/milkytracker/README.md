# MilkyTracker

MilkyTracker is a music tracker for composing and editing module-based music. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/MultiMedia/Audio/MilkyTracker`.
