# MultiPuzzle

MultiPuzzle is a collection of puzzle games. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Games/Puzzle/MultiPuzzle`.

The recipe includes catalog and icon installation steps.
