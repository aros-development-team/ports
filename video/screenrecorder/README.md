# ScreenRecorder

ScreenRecorder captures screen activity as video. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/MultiMedia/Video/ScreenRecorder`.

The recipe builds an AROS GUI application and includes audio support and localized catalogs.
