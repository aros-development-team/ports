# DOSBox

DOSBox emulates a DOS-compatible environment for running older PC programs. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Emu/DOSBox`.

The port includes a DOSBox configuration file.
