# Ctags

Ctags builds source-code tag indexes for navigation in editors. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/$(AROS_DIR_DEVELOPER)/Ctags`.
