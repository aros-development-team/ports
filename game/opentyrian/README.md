# OpenTyrian

OpenTyrian is an open-source implementation of the classic Tyrian shooter. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Games/Action/OpenTyrian`.

The port pins an upstream source commit rather than a release tag.
