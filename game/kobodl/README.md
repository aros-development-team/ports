# Kobo Deluxe

Kobo Deluxe is an arcade-style space shooter. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Games/Action/KoboDeluxe`.

The upstream download is marked as blocked by Cloudflare in `mmakefile.src`, and the parent MetaMake inclusion is commented out.
