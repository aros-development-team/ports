# MUIbase

MUIbase is a programmable database application with a MUI-based interface. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Office/MUIbase`.

The port uses the Zune NList class dependency and installs application resources along with the program.
