# Alacritty

Alacritty is a terminal emulator. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Utilities/Shell/Alacritty`.

This port requires the AROS Rust cross-toolchain and its adapted GUI and runtime dependencies.
