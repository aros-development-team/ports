# Bywater BASIC

Bywater BASIC is a BASIC-language interpreter. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/$(AROS_DIR_DEVELOPER)/BWBasic`.

The recipe also installs examples, manuals, and upstream BASIC test material.
