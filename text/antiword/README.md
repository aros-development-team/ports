# Antiword

Antiword extracts text from Microsoft Word documents. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Utilities/Text/Antiword`.

The port also contains an `AntiwordGUI` integration file and installs supporting conversion data.
