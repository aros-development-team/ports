# GOCR

GOCR is an optical character recognition program for extracting text from images. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Utilities/Text/Gocr`.
