# VICE

VICE emulates Commodore 8-bit computers and related peripherals. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Emu/Vice`.

The installation recipe includes multiple machine emulators and disk/cartridge utilities.
