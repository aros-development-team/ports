# abcm2ps

abcm2ps converts music written in ABC notation into printable music scores. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/MultiMedia/Audio/Abcm2ps`.

The port installs score formats and upstream examples along with the converter.
