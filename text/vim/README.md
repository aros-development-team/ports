# MUI-Vim

MUI-Vim provides a graphical MUI interface to the Vim text editor. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Utilities/Text/Vim`.

The port's recipe selects a Vim build with its MUI GUI.
