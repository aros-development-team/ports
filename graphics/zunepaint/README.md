# ZunePaint

ZunePaint is a Zune-based painting and image-editing application. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/MultiMedia/Gfx/ZunePaint`.
