# GrafX2

GrafX2 is a pixel-art image editor. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/MultiMedia/Gfx/GrafX2`.
