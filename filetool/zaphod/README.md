# Zaphod

Zaphod is a file editor for examining and changing file contents. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Utilities/Filetool/Zaphod`.
