# Circus Linux

Circus Linux is an arcade game inspired by classic circus-themed games. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Games/Action/CircusLinux`.
