# OpenTTD

OpenTTD is an open-source transport management and simulation game. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Games/Strategy/OpenTTD`.

The port pins an upstream source commit, as documented in the recipe.
