# MathX

MathX is a MUI-based mathematics application. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Utilities/Scientific/MathX`.

The source includes platform-specific MetaMake declarations that are commented out; do not infer automatic build inclusion from the presence of the recipe.
