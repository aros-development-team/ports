# GNU cflow

GNU cflow analyzes C code and generates function call graphs. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/$(AROS_DIR_DEVELOPER)/CFlow`.
