# WormWars

WormWars is an arcade action game. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Games/Action/WormWars`.

The recipe warns that its source package is no longer available at the configured AROS Archives URL; availability must not be assumed.
