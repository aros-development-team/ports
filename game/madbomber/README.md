# Mad Bomber

Mad Bomber is a classic arcade-style bomb-catching game. This directory supplies the integration maintained in AROS Ports.

The [AROS MetaMake recipe](mmakefile.src) fetches the upstream source and defines its AROS build or packaging steps and destination under `$(AROS_CONTRIB)/Games/Action/MadBomber`.
